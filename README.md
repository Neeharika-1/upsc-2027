# UPSC 2027 Workspace

A personal study workspace: daily floor and class pace, the Mains-First plan, a master syllabus checklist, an error log and a mock score log.

- Sign in with Google to sync progress across devices (Firebase Authentication + Firestore).
- Data is stored under `users/<your uid>/kv/*` and protected by Firestore rules, so only the signed-in owner can read or write it.
- Install it on a phone with "Add to Home Screen".

Files: `index.html` (the whole app), `manifest.webmanifest`, and icons.
